# Кто хочет представить себя миллионером

Статический HTML-сайт для корпоративной игры в формате пародии на "Кто хочет стать миллионером". Сайт можно опубликовать через GitHub Pages без сборки, npm и сервера.

## Как загрузить в GitHub

1. Создайте новый репозиторий на GitHub.
2. Загрузите в репозиторий файлы из этой папки.
3. В репозитории откройте `Settings -> Pages`.
4. В блоке `Build and deployment` выберите:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - папка: `/root`
5. Нажмите `Save`.

После публикации GitHub покажет ссылку вида:

```text
https://your-name.github.io/repository-name/
```

## Какие файлы важны

- `index.html` — основная страница для GitHub Pages.
- `*.mp3` — звуки игры, должны лежать рядом с `index.html`.
- `questionnaire.md` — готовый список вопросов для Google Формы.
- `dist/` — копия сайта со звуками для другого статического хостинга, можно оставить.
- `.nojekyll` — помогает GitHub Pages публиковать статические файлы без обработки Jekyll.

## Звуки

Сайт ожидает такие файлы рядом с `index.html`:

- `intro.mp3`
- `first question begin.mp3`
- `back.mp3`
- `final question.mp3`
- `answer.mp3`
- `first question.mp3`
- `10 question right.mp3`
- `right answer.mp3`
- `wrong answer.mp3`
- `loose.mp3`
- `win.mp3`
- `5050.mp3`
- `audience.mp3`
- `friend.mp3`

Важно: современные браузеры могут блокировать автоматическое проигрывание до первого клика пользователя. После нажатия `Начать игру` звуки уже работают как обычная часть игры.

## Google Форма и база сотрудников

1. Создайте Google Форму по списку из `questionnaire.md`.
2. Подключите ответы формы к Google Таблице.
3. В Google Таблице выберите `Файл -> Поделиться -> Опубликовать в интернете`.
4. Опубликуйте лист как CSV.
5. В игре нажмите `База и Firebase` и вставьте CSV URL.

## Firebase

Firebase не обязателен для теста: без него результаты сохраняются локально в браузере.

Для общей турнирной таблицы:

1. Создайте проект Firebase.
2. Включите Cloud Firestore.
3. Создайте Web App и скопируйте Firebase config JSON.
4. В игре нажмите `База и Firebase` и вставьте config.

Коллекция для результатов называется `leaderboard`.
